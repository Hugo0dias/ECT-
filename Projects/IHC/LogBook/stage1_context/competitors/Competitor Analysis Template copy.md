# Competitor Analysis: Darebee 
## General Information 
- **Name of System:** Darebee 
- **Company/Developer:** Darebee
- **Website/Product Page:**  http://darebee.com/
- **Version/Release Date:** 1-3-2023 
- **Platform(s) Supported:** Web 
- **Target Audience:** Pessoal que frequenta ginásio

--- 
## Core Functionality 

**Primary Purpose:** O sistema pretende garantir apoio aos seus utilizadores na modalidade do ginásio

**Key Features:** - Workouts - Programs - Chalenges - Guides - Collection - Community   

**Unique Selling Points (USPs):** - Donations

**Limitations/Weaknesses:** - O sistema encontra-se mal desenhado. O sistema é pouco específico relativamente à execução de exercícios
