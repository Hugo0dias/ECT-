## D.2. Prototype Evaluation

### Notas
- Dúvida se é preciso fazer login para criar workouts
- 'Add exercise' confundido com 'Save' nos workouts - Resolvido separando exercícios por blocos? - P1
- Colocar SAVED mais próximo ao 'Save' (popup?)
- 2 Botões para Workouts é confuso (mudar nome do Record Workouts) - P2
- Adicionar notas pode ser confuso com Obs. (mudar nome) - P3
- Data pode ser difícil de ver nos records
- Utilizador pode carregar no workout quando quer checar o progresso (talvez adicionar link ao progresso na lista de Workouts) - P4
- 'Add to' é confuso (pode ser confundido com os favoritos) 
- Difícil de ver o '+' ao adicionar exercício ao workout - P5
- Alguma indicação visual que o exercício foi adicionado 
- opção de remover exercício do workout - P6
- Botão para sair do teclado pode não ser identificado
- Opção de adicionar exercício na própria página de favoritos - P7
- Opçao de navegaçao, i.e, setas para voltar atrás - P8
- Adicionar um delete aos planos
